Todo List Project

A simple Todo List web application built using HTML, CSS, and JavaScript.

Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Clear all tasks
- Tasks saved using Local Storage

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download the project
2. Open "index.html" in a browser
